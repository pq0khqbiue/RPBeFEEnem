# 薪资核算与发放系统简介

## 核心功能
- **薪资核算模块**：自动计算员工薪资，包括基本工资、奖金、扣款等。
- **薪资发放模块**：实现薪资的自动发放，支持多种支付方式。
- **查询统计模块**：提供薪资数据的查询和统计功能，生成报表。
- **报表管理模块**：管理各种薪资报表，方便数据分析和决策。

## 适用场景
- 企业内部薪资管理
- 人力资源管理
- 薪资核算自动化需求
- 薪资数据统计与分析

## 技术特点
- **模块化设计**：清晰的结构划分，易于维护和扩展。
- **UML建模**：使用UML工具进行用例图与类图绘制，确保系统逻辑清晰。
- **技术栈**：后端采用Java+MySQL，前端使用Vue框架，确保系统稳定性和安全性。
- **自动化算薪**：集成自动化算薪引擎，提高薪资核算效率。
- **智能个税计算**：动态计算个人所得税，确保合规性。
- **电子工资条**：一键发送电子工资条，提升用户体验。
